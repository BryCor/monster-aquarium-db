# Monster Aquarium Inc - Database Project (Queens, NY)

This project models a small Aquarium & Fish Care Store database using MySQL.

## Files Included
- /diagrams: Chen ER diagram and MySQL Workbench UML/EER diagram
- /sql: SQL scripts to create the database and tables (and sample queries if included)
- /workbench: MySQL Workbench model file (.mwb)
- /report: Final project report (PDF)
